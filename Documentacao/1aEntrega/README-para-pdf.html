2. Descrição e Contextualização

2.1. Descrição do Projeto e Problema a Resolver

Ter um pequeno jardim em casa pode ajudar a equilibrar o bem-estar que, cada vez mais, pessoas procuram no seu lar. No entanto, o ritmo acelerado do dia a dia deixa qualquer um com os horários menos dedicados às plantas, levando a que muitas vezes sejam esquecidas ou mal cuidadas.

Pretendemos, com este projeto, ajudar todos os PlantLovers a estarem mais atentos às necessidades das suas plantas, mesmo que o seu dia a dia seja num ritmo mais acelerado do que aquilo que eles gostariam.

2.2. Motivação e Objetivos

  • Motivação: Tendo vários PlantLovers na constituição do grupo, foi fácil chegar à ideia deste projeto, pois tem sido um dos desafios ao longo do curso: manter todas as plantas de casa bem cuidadas e saudáveis.
  • Objetivos:
    • Objetivo 1: Criar protótipo IoT baseado em ESP32 para recolha de dados.
    • Objetivo 2: Implementar servidor web e base de dados relacional.
    • Objetivo 3: Desenvolver modelo preditivo de IA para sugerir um melhor cuidado de determinada planta.

2.3. Público-Alvo

Amantes de plantas, com vidas activas e agitadas.

2.4. Fases do Projeto

Seguindo a sugestão do docente de Sistemas Distribuídos, o projeto será desenvolvido em duas fases:

Fase 1 – Monitorização e alertas (até ao Milestone 2, 30-11-2026)

  • Leitura da humidade do solo, humidade e temperatura do ar e luminosidade.
  • Envio periódico dos dados para o servidor via REST e armazenamento em MySQL.
  • Alertas ao utilizador quando a planta precisa de atenção (ex.: solo demasiado seco).
  • Recolha contínua de dados nas 4 casas, com pelo menos uma planta da mesma espécie em todas.

Fase 2 – Atuação automática (até à entrega final, 01-02-2027)

  • Rega automática através de uma mini bomba de água controlada por relé.
  • Reservatório de água com sensor de nível e alerta quando a água estiver a acabar.
  • Sugestões de cuidados geradas pelo modelo de IA, com base nos dados recolhidos e na previsão meteorológica.

3.3. Guiões de Teste Preliminares

Guião de Teste 1: Registo e Envio de Dados do Sensor

  1. O utilizador liga o sistema IoT à corrente elétrica e à rede Wi-Fi.
  2. O ESP32 lê os valores dos sensores.
  3. O ESP32 envia os dados formatados via POST HTTP REST para o servidor.
  4. O servidor valida o POST e armazena os dados na base de dados.
  5. Resultado Esperado: Os dados aparecem corretamente registados com timestamp na base de dados.

Guião de Teste 2: Obtenção de Sugestões de Cuidados Personalizados

  1. O utilizador acede à interface do sistema ou consulta o endpoint de sugestões.
  2. O modelo de Inteligência Artificial processa o histórico de dados dos sensores e os dados adicionais externos.
  3. O sistema cria indicações dos cuidados a ter.
  4. Resultado Esperado: São apresentadas até 3 indicações dos cuidados mais imediatos a implementar.

4. Arquitetura e Design da Solução

4.1. Arquitetura Computacional (Provisória)

Diagrama de blocos conceptual (imagem gerada por IA). Notas sobre a arquitetura real:

  • ESP32: o sistema terá 4 dispositivos, um em casa de cada elemento do grupo, todos a enviar dados para o mesmo servidor online. Assim, o modelo de IA é treinado com dados reais recolhidos.
  • Fonte de dados externa: o modelo de IA vai combinar o histórico dos sensores com a previsão meteorológica da API Open-Meteo (temperatura, humidade, precipitação e radiação solar).
  • Utilizador: consulta os dados, os alertas e as sugestões de cuidados através do dashboard web, que comunica com a API REST.

4.2. Esboço do Artefacto Físico

Esboço conceptual (imagem gerada por IA). Notas sobre a implementação real:

  • Humidade do solo: será usado um sensor capacitivo, mais resistente à corrosão do que o modelo resistivo ilustrado.
  • pH do solo: a sonda ilustrada destina-se a líquidos.
  • Painel solar: apenas para a versão exterior, como alimentação auxiliar.
  • Fase 2: a base do vaso funcionará como reservatório de água, com mini bomba controlada pelo relé e sensor de nível para alertar quando a água estiver a acabar.
